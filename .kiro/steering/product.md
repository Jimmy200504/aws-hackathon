# SkillWeave product steering

The product objective is to improve first-page job relevance for 1111 search while making every graph contribution inspectable.

Non-negotiable rules:

- Never claim an offline lift that is not present in the checked-in report.
- Never use post-cutoff JD text to create graph nodes or edges.
- Preserve the official API contract before adding optional fields.
- LLM output is a proposal; deterministic evidence validation controls graph publication.
- Formal evaluation cannot depend on talentNo because the judge payload does not provide it.
